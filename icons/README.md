# Ícones do BlenderiX

Assets gráficos do aplicativo (logo, ícones de sistema e variantes).

```
icons/icon.png          # ícone PNG principal do app (512x512, embarcado e instalado)
icons/options/          # 10 variantes do ícone do app (ver options/README.md)
release/datafiles/icons_svg/blenderix.svg       # ícone SVG embarcado no app
release/freedesktop/icons/                       # ícones Linux (scalable/symbolic)
release/darwin/blender_liquid_glass.icon/        # bundle de ícone macOS
release/windows/icons/                           # winblender.ico / .rc
```

O logo base (SVG) vem de
`release/darwin/blender_liquid_glass.icon/Assets/Blender Logo.svg` e é a
fonte de todas as variantes geradas por script.

Detalhes de geração e aplicação: [`options/README.md`](options/README.md).
